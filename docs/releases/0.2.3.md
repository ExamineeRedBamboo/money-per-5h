# 0.2.3

首个准备公开的手动用量版本，支持 Android 11 及以上。

## 功能

- “用量 / 记录”两页，5 小时与每周额度分别显示剩余比例和重置时间。
- 十个金额按钮组合输入，停手 3 秒后保存；直接输入金额时明确点击保存。
- 倍数换算两个限额，确认后有效 30 天。修改倍数保留已用金额和额度窗口，按新限额重算剩余比例。
- 按北京时间汇总含本周在内的 12 周每日记录，并保留全部历史明细。
- 删除立即保存，在当前记录页内可撤销最近一次删除；进入后台或离开记录页后撤销失效。
- 本地存储，无账号、网络、外部应用读取或消费提醒。
- 简洁金额区，保留“点击下方按钮组合目标金额”提示。

## 验证范围

Release 构建成功，45 项 JVM 测试通过，Release Lint 0 问题。已完成开发包真机安装及启动验证；更多设备、系统回收、输入法和长历史场景仍需持续验证。

## 安装包

首发源码采用 MIT 许可证。正式签名 APK 尚未发布，安装包后续通过 GitHub Releases 提供。Debug 包供开发使用；切换到不同签名的正式包需要注意卸载会清除本机数据。
